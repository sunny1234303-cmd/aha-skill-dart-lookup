# dart-lookup

DART(전자공시시스템)에서 한국 상장사 사업보고서를 직접 열어 매출액·영업이익·부채비율을 확인하고, 동종업계 비교와 시장 현황까지 더해 시사점을 정리하는 재무 분석 스킬입니다. 웹검색 수치는 독립된 출처 2곳 이상에서 교차 검증한 것만 씁니다.

[아하모먼트 Friends 소개 페이지에서 먼저 보기 →](https://ahamoment-platform.vercel.app/friends/skill.html?slug=dart-lookup)
